# Dataset

`link_dataset.csv` contains synthetic wireless-link observations generated by the simulator.

Each row represents a candidate link at a particular simulation time.

### Columns

- `distance_m`: node-to-node distance
- `rssi_dbm`: received signal strength
- `noise_dbm`: simulated noise floor
- `snr_db`: signal-to-noise ratio
- `interference_db`: interference level
- `previous_success_rate`: recent success rate
- `latency_ms`: simulated link latency
- `reliable_link`: target label (1 = reliable, 0 = unreliable)

The dataset is synthetic and intended for reproducible simulation/ML experimentation.
